# ML Classification Pipeline

End-to-end machine learning classification pipeline demonstrating core computational data science skills.

## Overview
This project builds a binary classification model (e.g., predicting student success or similar outcomes) using synthetic data. It covers the full pipeline from data generation to model evaluation.

## Features
- Synthetic data generation with realistic feature relationships
- Data preprocessing and scaling
- Model comparison: Logistic Regression vs Random Forest
- Evaluation: Accuracy, ROC-AUC, classification report, confusion matrix
- Cross-validation

## Setup & Run
```bash
pip install -r requirements.txt
python classification_pipeline.py
```

## Skills Demonstrated
- scikit-learn pipelines and best practices
- Classification metrics and model selection
- Feature scaling and train/test split
- Visualization of results
